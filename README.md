# 同行 · 伴侣关系成长评估 V2.0

原创研究原型，尚未完成信效度验证。不是官方 PREPARE/ENRICH、CSI 或 FACES IV 量表，不用于诊断、临床界值判断、关系分类或离婚概率预测。

纯静态 HTML / JavaScript，无后端、无 API 密钥、无第三方脚本。问卷、导入、分析、报告全部在当前浏览器处理；无账号、云存储或同步。适合先用模拟数据试用并接受专家审阅。

## 功能与题库

- 180 核心题，16 个维度、45 个二级构念；婚前与已婚可用，可选不适用或拒答。
- 68 专项题：依恋 12、原生家庭经历 8、婚前期待 12、生活压力 8、基督教信仰 12、安全筛查 10、开放题 6。
- 双人 A/B JSON 配对；编号、角色、关系阶段、测次、版本、数据格式及模拟标记检查。
- 自动计分、雷达图、双方评分对比、子构念、题目级差异、六种家庭互动模式及八周成长计划。
- 可选前后测差值；浏览器「打印 / 保存 PDF」。
- 专项依恋、原生家庭、婚前期待、生活压力、开放题目前仅收集供私下访谈，不生成独立自动报告。信仰仅描述性计分。

1–5 线性换算为 0–100，反向题用 6−x；至少 75% 有效题。家庭凝聚力、灵活性需三个子构念均可评分，总维度将不平衡模式反向后等权平均，子构念保留原方向。60、75、25 均为自定义讨论规则，无人口常模、百分位或临床意义。前后测只描述差值，不能推断干预效果。

## 隐私与安全边界

**公开仓库仅放源码和明确标注的模拟数据。绝不上传真实夫妻答卷、报告、联系方式或辅导记录。**

- 答案保留在页面内存，刷新或关闭会丢失未导出答案。导入文件只在浏览器读取，不发出网络上传请求。
- 导出 JSON 和打印 PDF 未加密；没有账号或权限控制。须通过双方同意的安全渠道交接并约定保留及删除期限。
- 本地处理不能保证完全保密。GitHub 可记录普通网站访问日志，设备、浏览器历史、扩展、下载文件和打印队列可能留下痕迹。不要在受监控或不安全设备上填写。
- 安全筛查不计入核心分。当前及所导入基线的任何安全题不是“否”或缺失，均暂停共同反馈报告；必须由受训人员私下核查。全为“否”也不代表已经确认安全，不应要求参与者改答案来通过。
- 共同报告不显示安全题、开放题、依恋和压力原始答案，但含双方分数和部分题目级结果。双方须分别同意分享这些内容；辅导员复核后方可共同反馈。本站不会自动发送报告。
- 安全筛查仍在导出 JSON 中，应仅交给获授权的辅导员私下保管。页面清除操作不会删除已经下载的文件、历史或系统痕迹。
- 美国资源：[National Domestic Violence Hotline](https://www.thehotline.org/)，800-799-7233；紧急危险拨 911。其他地区请使用当地服务。资源信息核对于 2026-11-25。

## 本地试用与模拟数据

打开 `index.html`，点击「模拟报告」即可查看。也可在项目目录运行 `python3 -m http.server 8765` 后访问本地网址。

[examples](examples/README.md) 的四份 JSON 均为固定规则构造的模拟数据，不含真实参与者。正常配对和前后测操作见该目录说明。测试仅验证程序行为，不能证明量表有效或实际安全。

## GitHub Pages 部署

1. 创建或使用 `tongxing-assessment` 仓库，将本目录文件保留结构上传至 `main` 根目录；只上传源码和 mock 示例。
2. 仓库 Settings → Pages → Source 选 **Deploy from a branch** → **main** / **(root)** → Save。
3. 等待 Pages 部署成功，使用 GitHub 显示的实际地址。预期格式为 `https://<owner>.github.io/tongxing-assessment/`；格式不是发布成功的证据。

无需安装依赖或构建。`.nojekyll` 标记静态发布；所有资源使用相对路径，兼容项目子路径。

官方部署说明：https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 程序检查

安装 Node.js 的开发环境可运行 `node tests/run.cjs`。检查题库完整性、评分与缺失规则、家庭模式方向、配对及输入验证、安全拦截、基线检查、转义、模拟报告和导入失败清除旧报告。
