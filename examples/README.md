# 模拟数据，非真实夫妻

本目录四个 mock JSON 均由固定规则人工构造，无真实夫妻、个人身份或真实辅导信息。每份含 `synthetic: true`，配对编号为 `SYNTHETIC-DEMO`。不要用这些数据判断系统有效性。

在网站「生成报告」页选择：

- 当前测次 A：mock-A-post.json
- 当前测次 B：mock-B-post.json
- 可选基线 A：mock-A-pre.json
- 可选基线 B：mock-B-pre.json

勾选分享核查后生成；报告会标明「模拟数据 · 非真实夫妻」，并展示前后测描述性差值。首页「模拟报告」无需文件即可查看。所有示例安全题均为“否”，仅为演示正常流程，不代表实际安全认证。

禁止将真实答案或报告添加到本目录或仓库任何位置。`.gitignore` 只是防误操作提示，不是隐私访问控制。
